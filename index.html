GitHub sync settings

Edits always autosave to this browser. To also auto-commit them to your GitHub repo (so the site itself stays current across devices), paste a token below.

Create at GitHub → Settings → Developer settings → Fine-grained tokens. Scope it to only this repository with Contents: Read and write permission (nothing else). The token is stored only in this browser. Anyone with access to this computer profile could read it, so never use a broadly-scoped token. Note: GitHub fine-grained tokens only work on repos owned by your own account or an organization you belong to — collaborators on someone else's personal repo need a token supplied by the owner, or move the repo to a (free) GitHub organization.
